# Version 1.x Documentation

This page documents the configuration for `@conarti/eslint-plugin-feature-sliced` version 1.x.

::: warning Note
Version 1.x uses the legacy `.eslintrc` configuration format and ESLint 8.x. For ESLint 9+ with Flat Config, please upgrade to [v2.0](/getting-started).
:::

## Installation

```sh
npm install -D @conarti/eslint-plugin-feature-sliced@^1.0.0 eslint-plugin-import eslint
```

**Requirements:**
- Node.js >= 14.0.0
- ESLint 7.x or 8.x

::: info Note
`eslint-plugin-import` is optional. You can skip it if you don't need import sorting.
:::

## Quick Start

Add `@conarti/feature-sliced/recommended` to the extends section of your `.eslintrc` configuration:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ]
}
```

This enables all rules with recommended settings.

## Configuration Presets

### recommended

Enables all rules with recommended settings, including import sorting:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ]
}
```

### rules

Enables only FSD rules without import sorting configuration:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/rules"
  ]
}
```

## Manual Configuration

To configure rules individually:

```json
{
  "plugins": [
    "@conarti/feature-sliced"
  ],
  "rules": {
    "@conarti/feature-sliced/layers-slices": "error",
    "@conarti/feature-sliced/absolute-relative": "error",
    "@conarti/feature-sliced/public-api": "error"
  }
}
```

## Rules

| Rule | Description | Fix |
|------|-------------|-----|
| `@conarti/feature-sliced/layers-slices` | Validates imports between layers and slices | |
| `@conarti/feature-sliced/absolute-relative` | Validates absolute and relative paths | |
| `@conarti/feature-sliced/public-api` | Enforces imports from public API | 💡 |
| `import/order` | Sorts imports (via eslint-plugin-import) | 🔧 |

## Rule Options

### layers-slices

```json
{
  "@conarti/feature-sliced/layers-slices": ["error", {
    "allowTypeImports": true,
    "ignorePatterns": ["**/legacy/**"]
  }]
}
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `allowTypeImports` | `boolean` | `true` | Allow type-only imports from any layer |
| `ignorePatterns` | `string[]` | `[]` | Glob patterns for import paths to ignore |

### absolute-relative

```json
{
  "@conarti/feature-sliced/absolute-relative": ["error", {
    "ignorePatterns": ["*.css"]
  }]
}
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `ignorePatterns` | `string[]` | `[]` | Glob patterns for import paths to ignore |

### public-api

```json
{
  "@conarti/feature-sliced/public-api": ["error", {
    "level": "segments"
  }]
}
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `level` | `'slices'` \| `'segments'` | `'slices'` | Validation depth level |

## Full Configuration Example

```json
{
  "plugins": [
    "@conarti/feature-sliced"
  ],
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ],
  "rules": {
    "@conarti/feature-sliced/layers-slices": ["error", {
      "allowTypeImports": true,
      "ignorePatterns": ["**/legacy/**/*"]
    }],
    "@conarti/feature-sliced/absolute-relative": ["error", {
      "ignorePatterns": ["*.css", "*.scss"]
    }],
    "@conarti/feature-sliced/public-api": ["error", {
      "level": "segments"
    }]
  }
}
```
