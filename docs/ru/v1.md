# Документация версии 1.x

На этой странице описана конфигурация `@conarti/eslint-plugin-feature-sliced` версии 1.x.

::: warning Обратите внимание
Версия 1.x использует устаревший формат конфигурации `.eslintrc` и ESLint 8.x. Для ESLint 9+ с Flat Config, пожалуйста, обновитесь до [v2.0](/ru/getting-started).
:::

## Установка

```sh
npm install -D @conarti/eslint-plugin-feature-sliced@^1.0.0 eslint-plugin-import eslint
```

**Требования:**
- Node.js >= 14.0.0
- ESLint 7.x или 8.x

::: info Примечание
`eslint-plugin-import` опционален. Можете пропустить его, если вам не нужна сортировка импортов.
:::

## Быстрый старт

Добавьте `@conarti/feature-sliced/recommended` в секцию extends вашего `.eslintrc`:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ]
}
```

Это включает все правила с рекомендуемыми настройками.

## Пресеты конфигурации

### recommended

Включает все правила с рекомендуемыми настройками, включая сортировку импортов:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ]
}
```

### rules

Включает только правила FSD без конфигурации сортировки импортов:

```json
{
  "extends": [
    "plugin:@conarti/feature-sliced/rules"
  ]
}
```

## Ручная конфигурация

Для индивидуальной настройки правил:

```json
{
  "plugins": [
    "@conarti/feature-sliced"
  ],
  "rules": {
    "@conarti/feature-sliced/layers-slices": "error",
    "@conarti/feature-sliced/absolute-relative": "error",
    "@conarti/feature-sliced/public-api": "error"
  }
}
```

## Правила

| Правило | Описание | Фикс |
|---------|----------|------|
| `@conarti/feature-sliced/layers-slices` | Проверяет импорты между слоями и слайсами | |
| `@conarti/feature-sliced/absolute-relative` | Проверяет абсолютные и относительные пути | |
| `@conarti/feature-sliced/public-api` | Требует импорты из public API | 💡 |
| `import/order` | Сортирует импорты (через eslint-plugin-import) | 🔧 |

## Опции правил

### layers-slices

```json
{
  "@conarti/feature-sliced/layers-slices": ["error", {
    "allowTypeImports": true,
    "ignorePatterns": ["**/legacy/**"]
  }]
}
```

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `allowTypeImports` | `boolean` | `true` | Разрешить type-only импорты из любого слоя |
| `ignorePatterns` | `string[]` | `[]` | Glob-паттерны путей импорта для игнорирования |

### absolute-relative

```json
{
  "@conarti/feature-sliced/absolute-relative": ["error", {
    "ignorePatterns": ["*.css"]
  }]
}
```

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `ignorePatterns` | `string[]` | `[]` | Glob-паттерны путей импорта для игнорирования |

### public-api

```json
{
  "@conarti/feature-sliced/public-api": ["error", {
    "level": "segments"
  }]
}
```

| Опция | Тип | По умолчанию | Описание |
|-------|-----|--------------|----------|
| `level` | `'slices'` \| `'segments'` | `'slices'` | Глубина валидации |

## Полный пример конфигурации

```json
{
  "plugins": [
    "@conarti/feature-sliced"
  ],
  "extends": [
    "plugin:@conarti/feature-sliced/recommended"
  ],
  "rules": {
    "@conarti/feature-sliced/layers-slices": ["error", {
      "allowTypeImports": true,
      "ignorePatterns": ["**/legacy/**/*"]
    }],
    "@conarti/feature-sliced/absolute-relative": ["error", {
      "ignorePatterns": ["*.css", "*.scss"]
    }],
    "@conarti/feature-sliced/public-api": ["error", {
      "level": "segments"
    }]
  }
}
```
